Isolated VM Attack Lab

Lab build and technical manual — Fall 2026

A virtual lab on my laptop with a Kali Linux attacker and a deliberately vulnerable Metasploitable 2 target on their own internal network. The target is cut off from the internet, so a machine built to be hacked never touches a real network. A class assignment only asked for an instruction manual. I picked this topic so I'd learn something building it.

  • Set up the network in VirtualBox: Kali gets internet through NAT plus a second adapter on an internal-only network, and the target sits on that internal network alone.
  • Disabled USB in the VM settings. VirtualBox kept turning it back on until I switched the pointing device to a PS/2 mouse.
  • Confirmed the target can't reach the internet, then logged in to its FTP server from Kali and used Wireshark to capture the username and password in plain text.
  • Wrote a 13-step manual for the build and tested it on my own hardware, which turned up steps that didn't match current versions of VirtualBox and Kali, like Kali naming its network interfaces eth0 and eth1.
